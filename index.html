01 / Pipeline：让仿真运动对上真实运动01 / Pipeline: match simulated motion to real motion

Proprioception（本体感知）提供关节位置；Differentiable Simulation（可微分仿真）把轨迹差异转成参数更新。Proprioception provides joint positions; differentiable simulation turns trajectory mismatch into parameter updates.

  1. 1

    采集一次真实运动Record one real trajectory

    已知驱动输入，记录关节位置 q(t)。Apply a known input and record joint positions q(t).

  2. 2

    给参数一个初始猜测Initialize object parameters

    猜测质量或弹性参数，运行交互仿真。Guess mass or elastic parameters and simulate the interaction.

  3. 3

    比较两条关节轨迹Compare joint trajectories

    模拟运动与真实运动的差异构成 loss。Use simulated-versus-measured joint motion as the loss.

  4. 4

    用梯度更新，再仿真Update with gradients; simulate again

    对参数求导并更新，重复第 2–4 步。Differentiate the loss, update parameters and repeat steps 2–4.

真实数据采一次；仿真反复运行。前提：机器人与交互模型、已知驱动输入，以及物体初始位置。Record real data once; repeat the simulation. Requires robot and interaction models, known inputs and initial object positions.
